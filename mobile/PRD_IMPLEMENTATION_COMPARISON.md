## 2. 详细对比分析

### 2.1 首页设计 (index.tsx)

#### PRD 设计要求

PRD Section 2.3.3 明确要求首页是语音对话主界面：

核心要素:
- 主界面是语音对话界面，不是输入框
- 消息列表区域（用户/AI 对话）
- 指令确认卡片
- 大圆形语音按钮（按住说话）
- 底部快捷操作栏（附件、相机、文件、切换文本）

#### 当前实现

当前实现的是超级输入框入口页，不是语音对话界面。

#### 差异分析

| 要素 | PRD 设计 | 当前实现 | 差异 |
|------|----------|----------|------|
| 主界面 | 语音对话（消息列表） | 超级输入框 | 不符合 |
| 核心交互 | 按住说话 | 文本输入 | 不符合 |
| 消息显示 | 对话消息列表 | 无 | 缺失 |
| 指令卡片 | 确认执行/修改/取消 | 无 | 缺失 |
| 快捷操作 | 附件/相机/文件/文本切换 | 仅语音按钮 | 简化 |

**结论**: 不符合 PRD 设计

PRD 中的首页是语音对话主界面，而我们实现的是超级输入框入口页。需要重构首页为语音对话界面。

- 首页（语音对话）
- 设备
- 项目
- 我的

#### 当前实现

自定义三 Tab 设计：云端 / 本地 / 我的

#### 差异分析

| 要素 | PRD 设计 | 当前实现 | 差异 |
|------|----------|----------|------|
| Tab 数量 | 4个 | 3个 | 简化 |
| 首页 | 语音对话 | 超级输入框 | 不符合 |
| 设备/项目 | 独立 Tab | 合并为本地 | 简化 |

## 3. 主要问题与建议

### 问题 1：首页不符合 PRD 设计

**PRD 要求**：首页是语音对话主界面  
**当前实现**：超级输入框入口页

**建议**：
将当前 app/(main)/index.tsx 改为语音对话界面，参考 PRD Section 2.3.3 的设计。

### 问题 2：Tab 导航与 PRD 不符

**PRD 要求**：4个 Tab（首页/设备/项目/我的）  
**当前实现**：3个 Tab（云端/本地/我的）

**建议**：
按照 PRD 设计改为 4 个 Tab，设备/项目作为独立 Tab。

### 问题 3：缺少双模式切换

**PRD 要求**：ASR 语音模式和文本模式可切换  
**当前实现**：只有语音模式

**建议**：
在语音界面添加文本输入切换按钮。

### 问题 4：会员订阅功能缺失

**PRD 要求**：完整的订阅功能  
**当前实现**：未实现

**建议**：
后续迭代补充订阅功能。
