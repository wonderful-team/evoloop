## 🔧 技术实现建议

### 需要新增的模块
```
mobile/
├── components/
│   ├── chat/
│   │   ├── ArtifactCard.tsx       # Artifact 展示
│   │   ├── DiffViewer.tsx         # Diff 查看器
│   │   ├── StepsIndicator.tsx     # 步骤指示器
│   │   ├── ThoughtCard.tsx        # 思考卡片
│   │   ├── QuotePreview.tsx       # 引用预览
│   │   └── ThreadList.tsx         # 会话列表
│   ├── skill/
│   │   ├── SkillCard.tsx          # 技能卡片
│   │   ├── SkillList.tsx          # 技能列表
│   │   ├── SkillDetail.tsx        # 技能详情
│   │   └── McpServerCard.tsx      # MCP 服务器卡片
│   └── context/
│       └── ContextDrawer.tsx      # 上下文抽屉
├── app/
│   └── (main)/
│       ├── threads.tsx            # 会话列表页面
│       └── skills.tsx             # 技能管理页面
└── services/
    └── api/
        ├── conversations.ts       # 会话管理 API
        ├── skills.ts              # 技能 API
        ├── artifacts.ts           # Artifacts API
        └── rewind.ts              # Rewind/Retry API
```

### 需要对接的关键 API

```typescript
// 会话管理
GET    /conversations              # 获取会话列表
POST   /conversations              # 新建会话
DELETE /conversations/:id          # 删除会话
GET    /conversations/:id/history  # 获取会话历史

// Rewind/Retry
POST   /conversations/:id/rewind   # 消息回退
POST   /conversations/:id/retry    # 消息重试

// Skills
GET    /skills                     # 获取技能列表
GET    /skills/:id                 # 获取技能详情
POST   /skills/:id/execute         # 执行技能
GET    /mcp/servers                # 获取 MCP 服务器列表

// Artifacts
GET    /conversations/:id/artifacts # 获取 Artifacts
GET    /artifacts/:id/download     # 下载 Artifact

// Memory
POST   /memory/concepts            # 添加到记忆
GET    /memory/concepts            # 获取记忆列表
```

- ✅ 基础聊天功能完整 (25/25)

4. 会话管理 - 基础功能缺失
