# EvoLoop 产品宣传视频制作需求文档 v1.0

---

## 一、项目概览

| 项目 | 内容 |
|------|------|
| 产品名称 | EvoLoop AI |
| 宣传口号 | 拥有属于你的AI数字员工 |
| Slogan (EN) | Evolution in Loop |
| 视频时长 | 90-100s |
| 画面比例 | 16:9 横屏（主）+ 9:16 竖屏裁切版（备用） |
| 输出分辨率 | 3840×2160 (4K) |
| 帧率 | 60fps（录屏） |
| 风格基调 | 科技感、激情、快节奏 |
| 背景音乐 | EDM / Synthwave，BPM 128-140，有强烈节奏感 |
| 语言 | 中文配音 + 中英双语字幕 |
| 核心展示 | 桌面端 + 移动端双端联动 |

## 二、分镜头脚本

### 符号说明

| 符号 | 含义 |
|------|------|
| DESKTOP | 桌面端操作录屏 |
| MOBILE | 手机端操作录屏 |
| B-ROLL | 实物拍摄/过渡镜头 |
| VFX | 后期特效/动效 |

## 九、注意事项 & 风险提示

1. **录屏环境**：录制前关闭所有无关应用和通知，保持桌面整洁（文件图标、dock 栏整理干净）。系统主题建议使用浅色或深色（统一整个视频）
2. **网络环境**：Agent 推理需保证网络通畅，避免录制时出现加载延迟。可考虑提前准备演示用的本地缓存/ Mock 数据
3. **数据安全**：所有示例项目中不要使用真实客户数据，使用 Demo 专用数据
4. **移动端模拟**：Android 操控演示建议使用 Android 模拟器 + scrcpy 连接，便于控制录制画面
5. **音画同步**：旁白录制时留好时间标记点，后期严格对齐画面
6. **备份工程**：每个版本都备份工程文件，避免软件崩溃导致工作丢失
7. **竖屏版**：竖屏版需要在横屏基础上重新裁剪构图，重点关注每个画面主体内容，而非简单等比缩放。关键信息（文字、操作按钮）应居中或上半部分
