## 产品简介

### 什么是 EvoLoop？

EvoLoop 是一款**智能开发助手**，它能够理解您的需求，帮助您：

- 📝 **编写代码** — 根据自然语言描述生成高质量代码
- 🔍 **理解项目** — 自动分析代码库结构和架构
- 🐛 **解决问题** — 诊断 Bug、提供修复建议
- 📚 **生成文档** — 自动撰写项目文档和 API 说明
- 🔄 **自动化任务** — 执行重复性开发工作

### 谁适合使用？

| 角色 | 使用场景 |
|:---|:---|
| **开发者** | 加速编码、代码审查、学习新技术 |
| **技术负责人** | 项目架构分析、技术文档生成 |
| **产品经理** | 快速理解技术方案、需求沟通 |
| **学习者** | 代码解读、编程学习辅助 |

## 快速上手

### 第一步：创建或导入项目

1. 打开 EvoLoop 桌面应用
2. 进入 **「项目」** 页面
3. 点击 **「新建项目」** 或选择已有项目
4. 系统会自动分析项目结构

> 💡 **提示**：首次导入项目时，系统需要建立知识索引，这可能需要几分钟时间。

### 第二步：开始对话

1. 切换到 **「对话」** 页面
2. 确保已选择正确的项目（左上角项目切换器）
3. 在输入框中描述您的需求
4. 点击发送或按 Enter 键

### 示例对话

```
您：帮我分析这个项目的整体架构

AI：好的，我来分析这个项目的架构...
    
    这是一个基于 FastAPI 的后端项目，主要包含以下模块：
    - app/core — 核心业务逻辑
    - app/api — API 接口定义
    - app/models — 数据模型
    ...
```

## 核心功能

### 1. 智能对话 💬

与 AI 进行自然语言交互，无需记忆复杂命令。

**支持的操作类型：**

| 类型 | 示例指令 |
|:---|:---|
| 代码生成 | "帮我写一个用户登录的 API 接口" |
| 代码解读 | "解释一下 auth.py 这个文件的作用" |
| Bug 诊断 | "这个错误是什么原因？[粘贴错误信息]" |
| 重构建议 | "如何优化这段代码的性能？" |
| 文档生成 | "为这个模块生成 API 文档" |

**进阶用法：**
- 上传图片（截图、流程图）让 AI 分析
- 附加文件作为参考上下文
- 使用语音输入（点击麦克风图标）

---

### 2. 项目管理 📁

集中管理您的所有开发项目。

**功能特性：**

- **文件浏览** — 查看项目目录结构和文件内容
- **语义搜索** — 根据功能描述搜索代码（而非仅关键字匹配）
- **任务追踪** — 管理开发任务和进度
- **甘特图** — 可视化项目时间线

**操作方式：**

1. 在项目列表中选择目标项目
2. 点击进入项目详情页
3. 使用顶部标签页切换不同视图

---

### 3. 上下文面板 🧠

对话界面右侧的上下文面板是您的"工作台"。

**面板内容：**

| 区域 | 用途 |
|:---|:---|
| **置顶文件** | 将常用文件固定在此，方便 AI 参考 |
| **运行时工具** | 查看 AI 当前可用的工具能力 |
| **外部链接** | 添加参考文档或 API 地址 |

**如何置顶文件：**
1. 在文件浏览器中找到目标文件
2. 右键点击 → 选择 "置顶到资源"
3. 文件会出现在上下文面板中

---

### 4. MCP 扩展能力 🔌

通过 MCP（Model Context Protocol）协议连接外部工具。

**已支持的扩展：**

| 扩展 | 功能 |
|:---|:---|
| **Git** | 执行 Git 操作、查看提交历史 |
| **数据库** | 查询和分析数据库内容 |
| **搜索引擎** | 联网搜索技术资料 |
| **文件系统** | 访问本地文件（超出项目范围） |

**如何添加扩展：**
1. 进入 **「MCP 服务器」** 页面
2. 点击 **「添加服务器」**
3. 填写服务器名称和启动命令
4. 保存后系统自动连接

---

### 5. 个性化设置 ⚙️

根据您的习惯定制 EvoLoop。

**可配置项：**

| 设置项 | 说明 |
|:---|:---|
| **语言** | 切换界面语言（中文/English） |
| **设备名称** | 在多设备环境中标识当前设备 |
| **项目根目录** | 设置默认的项目扫描路径 |
| **AI 模型** | 选择使用的语言模型和 API |
| **审批模式** | 控制 AI 执行操作前是否需要您确认 |
| **主题** | 浅色/深色/跟随系统 |

## 使用技巧

### 💡 提高回复质量的技巧

1. **提供足够上下文**
   - ❌ "这个函数有问题"
   - ✅ "auth.py 中的 validate_token 函数返回了 None，但我期望它返回用户对象"

2. **明确期望结果**
   - ❌ "帮我改一下代码"
   - ✅ "把这个函数改成异步版本，并添加错误处理"

3. **善用文件置顶**
   - 将相关文件置顶到上下文面板
   - AI 会自动参考这些文件

4. **分步骤提问**
   - 复杂任务拆分成多个小步骤
   - 每步确认后再继续

### ⌨️ 快捷操作

| 操作 | 快捷方式 |
|:---|:---|
| 发送消息 | `Enter` |
| 换行（不发送） | `Shift + Enter` |
| 新建对话 | 点击侧边栏 + 按钮 |
| 停止生成 | 点击红色停止按钮 |

### 🔄 审批模式说明

EvoLoop 支持两种工作模式：

| 模式 | 说明 | 适用场景 |
|:---|:---|:---|
| **审批模式（默认）** | AI 在执行重要操作前会请求您确认 | 生产环境、敏感操作 |
| **自主模式** | AI 自动执行低风险操作，仅高风险操作请求确认 | 开发环境、快速迭代 |

可在 **设置 → 常规 → Agent Behavior** 中切换。

## 常见问题

### Q1: 为什么 AI 的回复有时会很慢？

**可能原因：**
- 项目正在建立索引（首次导入时）
- 请求涉及大量文件分析
- 网络连接不稳定

**解决方案：**
- 等待索引完成（可在项目详情页查看状态）
- 尝试将问题拆分成更小的部分
- 检查网络连接

---

### Q2: AI 如何知道我的项目结构？

EvoLoop 会在后台建立项目的**知识索引**，包括：

1. **文件结构** — 目录树和文件关系
2. **代码语义** — 函数、类、变量的含义
3. **依赖关系** — 模块间的调用关系

这个过程是自动的，您只需等待索引完成即可。

---

### Q3: 我可以让 AI 执行危险操作吗？

EvoLoop 内置了安全机制：

- **默认需要审批** — 文件修改、命令执行等操作会弹出审批卡片
- **风险等级标识** — 高风险操作会有明显警告
- **可回滚** — 建议配合 Git 使用，以便撤销意外更改

---

### Q4: 如何重新开始新手引导？

1. 进入 **设置 → 常规**
2. 滚动到页面底部
3. 点击 **「重新播放引导」** 按钮

---

### Q5: 支持哪些编程语言？

EvoLoop 支持主流编程语言，包括但不限于：

- **后端**：Python、Java、Go、Rust、Node.js
- **前端**：TypeScript、JavaScript、React、Vue
- **移动端**：Swift、Kotlin、Flutter
- **其他**：SQL、Shell、Markdown

---

### Q6: 数据安全吗？

- 您的代码 **不会上传到公有云**（除非您使用云端 LLM）
- 本地索引数据存储在您的设备上
- 如使用私有 LLM（如本地 Ollama），数据完全离线
