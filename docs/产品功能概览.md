## 🎯 产品定位

**EvoLoop** 是一款面向开发者的 **AI 驱动型智能开发助手**，通过自然语言交互帮助用户完成编码、调试、文档生成等开发工作。

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│    👤 开发者  ───── 自然语言 ─────▶  🤖 EvoLoop AI Agent        │
│                                                                 │
│         "帮我实现用户登录功能"                                    │
│                     ↓                                           │
│              ┌─────────────────┐                                │
│              │  理解 → 规划 → 执行  │                            │
│              └─────────────────┘                                │
│                     ↓                                           │
│         ✅ 代码生成 + 测试 + 文档                                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 🛡️ 安全机制

### Human-in-the-Loop (HITL) 审批

对于以下操作，系统会请求用户确认：

| 操作类型 | 风险级别 | 审批方式 |
|:---|:---:|:---|
| 查看文件内容 | 🟢 低 | 自动执行 |
| 修改单个文件 | 🟡 中 | 弹出审批卡片 |
| 执行 Shell 命令 | 🔴 高 | 强制审批 + 警告 |
| 批量文件操作 | 🔴 高 | 显示完整 Diff 后审批 |

### 自主模式切换

用户可在 **设置 → 常规** 中切换：

- **审批模式**（默认）：所有敏感操作需确认
- **自主模式**：仅高风险操作需确认

## 🔧 扩展能力 (MCP)

EvoLoop 通过 **Model Context Protocol** 支持动态扩展：

```
┌─────────────────────────────────────────────────────┐
│                    EvoLoop Agent                    │
│                         │                           │
│    ┌────────────────────┼────────────────────┐      │
│    │                    │                    │      │
│    ▼                    ▼                    ▼      │
│ ┌──────┐           ┌──────┐           ┌──────┐     │
│ │ Git  │           │ 数据库 │           │ 搜索  │    │
│ │Server│           │Server│           │Server│     │
│ └──────┘           └──────┘           └──────┘     │
│                                                     │
│  更多工具可通过配置动态挂载...                        │
└─────────────────────────────────────────────────────┘
```

**支持的扩展类型**：
- 版本控制（Git）
- 数据库查询
- 网络搜索
- 文件系统访问
- 自定义工具

## 📊 典型使用场景

### 场景 1：快速理解陌生代码库

```
👤 您：帮我分析这个项目的架构，特别是用户认证模块

🤖 AI：好的，我来分析这个项目...

      📁 项目结构分析
      ├── app/auth — 用户认证模块
      │   ├── jwt.py — JWT Token 生成与验证
      │   ├── password.py — 密码哈希处理
      │   └── middleware.py — 认证中间件
      ...
      
      🔑 认证流程：
      1. 用户提交凭据 → 2. 验证密码 → 3. 生成 JWT → 4. 返回客户端
```

### 场景 2：实现新功能

```
👤 您：帮我实现一个邮箱验证功能，用户注册后发送验证链接

🤖 AI：好的，我来实现这个功能。需要以下步骤：
      
      📋 执行计划：
      1. 创建验证 Token 生成逻辑
      2. 添加邮件发送服务
      3. 实现验证 API 端点
      4. 更新用户模型添加验证状态字段
      
      [需要审批] 是否开始执行？
```

### 场景 3：调试错误

```
👤 您：运行时报错 "NoneType has no attribute 'id'"，怎么解决？
      [附带错误截图]

🤖 AI：根据错误信息和堆栈追踪，问题出在 user_service.py 第 45 行：
      
      ❌ 问题：get_current_user() 返回了 None，但代码假设它总是返回用户对象
      
      ✅ 修复建议：添加空值检查
      
      ```python
      user = get_current_user()
      if not user:
          raise HTTPException(status_code=401, detail="Not authenticated")
      ```
      
      [需要审批] 是否应用此修改？
```

## 🚀 开始使用

1. **下载安装** — 访问 [develop-assistant.cn](https://develop-assistant.cn) 下载对应平台版本
2. **配置 AI 模型** — 在设置中配置 LLM API（支持 OpenAI、Anthropic 或本地 Ollama）
3. **导入项目** — 在项目页面添加您的代码库
4. **开始对话** — 切换到对话页面，开始与 AI 协作
