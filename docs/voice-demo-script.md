# 语音驱动 MacOS 办公场景演示剧本

核心：**快**。语音只做快速响应操作，宏 + 轻量 Agent 秒级完成。

---

## 场景总览

| 场景 | 操作 | 响应时间 | 核心能力 |
|------|------|---------|---------|
| 系统控制 | 静音/调音量/截图 | <1s | 语音宏 |
| 应用导航 | 打开Chrome/进入后台 | <2s | 语音宏+桌面操控 |
| 文件操作 | 重命名/移动文件 | <5s | 宏+Agent |
| 快捷编辑 | 改文案/替换文字 | <10s | Agent轻量任务 |
| 信息查询 | 查任务/看进度 | <5s | Agent快速检索 |
| 组合操作 | 一条指令触发多步 | <8s | 宏编排 |

---

## 场景一：系统控制 — 即时响应

### 操作流程

| # | 语音指令 | 系统反应 | 耗时 |
|---|---------|---------|------|
| 1 | **"静音"** | 音量→0%，HUD显示✓ | <1s |
| 2 | **"音量调到一半"** | 系统音量→50% | <1s |
| 3 | **"截图标注"** | 触发宏：截屏→打开标注工具→标注→保存 | <3s |
| 4 | **"开始录制"** | 启动桌面录制，红色边框闪烁，标记按钮出现 | <2s |
| 5 | **"结束录制"** | 停止录制→弹出合成对话框 | <2s |

**演示要点：** 快速连续执行，展示语音到动作的零延迟

**涉及的宏：** 静音、音量一半、音量最大/最小、播放暂停、下一曲（87条预设宏中任选）

---

## 场景二：应用与页面导航 — 一句话到达

### 操作流程

| # | 语音指令 | 系统反应 | 耗时 |
|---|---------|---------|------|
| 1 | **"打开项目 mall-backend"** | 侧边栏→项目列表→进入项目详情 | <3s |
| 2 | **"查看任务"** | 切换到任务Tab | <2s |
| 3 | **"看下文件"** | 切换到文件Tab，展开目录树 | <2s |
| 4 | **"看看百科"** | 切换到Wiki/知识图谱Tab | <2s |
| 5 | **"回聊天"** | 返回聊天页面 | <2s |

**演示要点：** 页面间快速跳转，展示语音导航的高效

**涉及功能：** 语音L0路由→前端页面导航，87条宏中的导航类指令

## 场景三：桌面应用操控 — 语音指挥MacOS

### 操作流程

| # | 语音指令 | 系统反应 | 耗时 |
|---|---------|---------|------|
| 1 | **"打开Chrome浏览器"** | Agent→Dock→打开Chrome | <3s |
| 2 | **"进入管理后台"** | Agent在Chrome地址栏输入URL→回车 | <3s |
| 3 | **"登录"** | Agent找到登录框→填入账号密码→登录 | <5s |
| 4 | **"查看订单列表"** | Agent点击导航菜单→进入订单页面 | <3s |
| 5 | **"导出今天的订单"** | Agent点击导出按钮→选择日期→下载 | <5s |

**演示要点：** Agent像真人一样操作MacOS桌面应用（浏览器/SaaS后台）

**涉及功能：** MacOS桌面操控（atlas_apps动作录制回放）、Agent流程编排

## 录制分镜建议

### 第一镜：快速连击（展示响应速度）

```
画面：桌面全屏，右下角Voice HUD浮窗
语音：用户连续说3-4条指令
  "静音"         → HUD瞬间响应，音量图标变化
  "打开Chrome"   → Chrome自动打开
  "查看任务"     → 页面跳到任务Tab
  "回聊天"       → 跳回聊天页
旁白："EvoLoop 语音驱动，一句话直达。"
时长：8-10秒
```

### 第二镜：组合工作流（展示宏能力）

```
画面：用户坐下，说一句话触发完整工作流
语音："准备周报"
系统：自动收集任务→生成文档→保存→语音播报
旁白："自定义宏，让复杂工作流一句话完成。"
时长：10-12秒
```

### 第三镜：桌面操控（展示Agent能力）

```
画面：Agent自动打开浏览器、操作后台
语音："打开管理后台，导出今天订单"
系统：Agent操作Chrome→登录→导出
旁白："Agent 像真人一样操作你的桌面。"
时长：12-15秒
```

### 第四镜：语音查询（展示知识问答）

```
画面：用户边做其他事边问
语音："mall-backend 什么进度"
系统：立即调出统计数据并语音播报
旁白："随时问，随时答，你的AI数字员工。"
时长：8-10秒
```

## 与当前脚本的衔接

现有 `evoloop-demo.applescript` 可自动完成的操作（用于录屏素材）：

| 脚本场景 | 对应演示 | 说明 |
|---------|---------|------|
| Sidebar导航 | 场景二"一句话到达" | 录制自动切换页面 |
| 项目Tab切换 | 场景二 | 文件/任务/百科快速切换 |
| 生成画像对话框 | 场景四的延伸 | 展示项目分析能力 |
| MCP工具添加 | 场景六的延伸 | 展示工具扩展能力 |
| 指令库87条宏 | 场景一 | 展示预设宏列表 |

语音部分（HUD、F12触发、ASR识别、TTS播报、MacOS操控）需**实拍录屏**，脚本主要用于自动生成辅助素材。
