# 新手引导系统说明

> 帮助新用户快速了解 EvoLoop 核心功能

---

## 概述

EvoLoop 内置了一套**聚光灯式新手引导系统**，当用户首次使用桌面客户端时，会自动启动引导流程，逐步介绍各个核心功能区域。

---

## 引导流程

### 引导步骤一览

| 步骤 | 目标区域 | 标题 | 说明 |
|:---:|:---|:---|:---|
| 1 | Logo | 欢迎使用 EvoLoop | 欢迎语和引导说明 |
| 2 | 对话菜单 | 智能对话 | 介绍 AI 交互入口 |
| 3 | 项目菜单 | 项目管理 | 介绍项目管理功能 |
| 4 | MCP 菜单 | 扩展能力 | 介绍外部工具连接 |
| 5 | 设置菜单 | 个性化配置 | 介绍配置选项 |
| 6 | 对话侧边栏 | 对话历史 | 介绍会话管理 |
| 7 | 消息区域 | 消息区域 | 介绍对话展示 |
| 8 | 上下文面板 | 上下文面板 | 介绍资源管理 |
| 9 | 输入框 | 开始对话 | 引导用户发送第一条消息 |

1. **遮盖背景** — 半透明深色遮罩覆盖整个界面

3. **发光边框** — 目标区域外围有主色调发光效果
4. **提示卡片** — 在目标区域旁边显示说明文字

## 触发条件

### 自动触发

- **首次打开应用**：如果用户从未完成过引导，系统会在应用加载后 800ms 自动启动

### 手动触发

用户可以随时重新播放引导：

1. 进入 **设置** 页面
2. 切换到 **常规** 标签
3. 滚动到页面底部
4. 点击 **「重新播放引导」** 按钮

---

## 用户操作

在引导过程中，用户可以：

| 操作 | 按钮/方式 | 效果 |
|:---|:---|:---|
| **前进** | 点击「下一步」 | 进入下一个引导步骤 |
| **后退** | 点击「上一步」 | 返回上一个引导步骤 |
| **跳过** | 点击右上角 ✕ | 立即结束引导，标记为已完成 |
| **完成** | 最后一步点击「开始使用」 | 正常结束引导 |

---

## 进度指示

引导卡片底部有进度条，显示当前处于第几步：

```
● ● ━━ ● ● ● ● ● ●
      ↑
   当前步骤
```

- **圆点**：已完成/未完成的步骤
- **长条**：当前步骤（高亮显示）

## 多语言支持

引导系统支持中文和英文两种语言，会自动跟随系统语言设置。

| 语言 | 界面元素示例 |
|:---|:---|
| 中文 | 「上一步」「下一步」「开始使用」 |
| English | "Previous" "Next" "Get Started" |

## 技术细节（供管理员参考）

### 状态存储

引导完成状态存储在浏览器的 `localStorage` 中：

- **键名**：`evoloop_desktop_tour_seen`
- **值**：`"true"` 表示已完成

清除此键可重置引导状态：

```javascript
localStorage.removeItem("evoloop_desktop_tour_seen")
```

### 引导目标定位

系统通过 `data-tour` 属性定位各个引导目标：

| 属性值 | 对应元素 |
|:---|:---|
| `sidebar-logo` | 侧边栏 Logo |
| `sidebar-chat` | 对话菜单项 |
| `sidebar-projects` | 项目菜单项 |
| `sidebar-mcp` | MCP 菜单项 |
| `sidebar-settings` | 设置菜单项 |
| `chat-sidebar` | 对话侧边栏 |
| `chat-messages` | 消息区域 |
| `chat-context` | 上下文面板 |
| `chat-input` | 输入框 |

## 常见问题

### Q: 引导没有自动启动怎么办？

**可能原因**：
1. 您之前已完成过引导
2. 浏览器阻止了 localStorage 访问

**解决方案**：
- 在设置中点击「重新播放引导」按钮

---

### Q: 引导过程中可以点击被遮盖的区域吗？

**不可以**。引导过程中，遮盖区域不响应点击事件，确保用户专注于当前介绍的功能。

---

### Q: 跳过引导后还能再看吗？

**可以**。跳过或完成引导后，随时可以在 **设置 → 常规** 中重新播放。
