## 1. 系统总览 (System Overview)

EvoLoop 是一个**通用智能体系统 (Universal Agent System)**，采用 **LangGraph** 构建，实现跨平台（Web、桌面、移动端）的自主任务编排与执行。

```mermaid
graph TB
    subgraph "用户层 (User Layer)"
        WEB["🌐 Web Client<br>(React + Vite)"]
        DESKTOP["💻 Desktop App<br>(Tauri v2)"]
        MOBILE["📱 Mobile App<br>(Tauri Android/iOS)"]
    end
    
    subgraph "后端层 (Backend Layer)"
        API["FastAPI Server<br>/api/v1/*"]
        ENGINE["LangGraph Engine<br>(Agent Workflow)"]
        WORKER["Celery Worker<br>(Async Tasks)"]
    end
    
    subgraph "数据层 (Data Layer)"
        PG["PostgreSQL<br>(Relational)"]
        NEO4J["Neo4j<br>(Knowledge Graph)"]
        REDIS["Redis<br>(Queue + Cache)"]
    end
    
    subgraph "云层 (Cloud Layer)"
        EVOCLOUD["☁️ EvoCloud<br>(member-center)"]
    end
    
    subgraph "技能层 (Skill Cells)"
        BROWSER["🌐 Browser-Use<br>:8002"]
        GUI["🖥️ Agent-S<br>:8001"]
        CRAWLER["🕷️ Crawl4AI<br>:8004"]
    end
    
    WEB & DESKTOP & MOBILE --> API
    API --> ENGINE
    ENGINE --> WORKER
    ENGINE <--> PG & NEO4J & REDIS
    ENGINE <-.->|MCP| BROWSER & GUI & CRAWLER
    API <-->|WebSocket| EVOCLOUD
    MOBILE -.->|Direct REST| EVOCLOUD
```

## 4. 云端集成 (Cloud Integration)

### 4.1 通讯链路总览

EvoCloud 作为**中央枢纽**，连接桌面端 Agent 和移动端 App：

```mermaid
graph TB
    subgraph "本地环境 (Local)"
        DESKTOP["💻 Desktop Client<br>(Tauri)"]
        BACKEND["🏢 Python Backend<br>(FastAPI + LangGraph)"]
    end
    
    subgraph "云端 (Cloud)"
        EVOCLOUD["☁️ EvoCloud<br>(member-center)"]
    end
    
    subgraph "移动端 (Mobile)"
        MOBILE["📱 Mobile App<br>(Tauri Android/iOS)"]
    end
    
    %% Flow 1: Desktop -> Mobile
    DESKTOP -->|"1. REST API"| BACKEND
    BACKEND -->|"2. REST/WS"| EVOCLOUD
    EVOCLOUD -->|"3. Push Command"| MOBILE
    
    %% Flow 2: Mobile -> Backend
    MOBILE -->|"4. REST API"| EVOCLOUD
    EVOCLOUD -->|"5. WS Event"| BACKEND
```

## 8. 技术总结

| 层级 | 技术选型 | 说明 |
| :--- | :--- | :--- |
| **Agent 引擎** | LangGraph + LangChain | 状态图驱动的多节点工作流 |
| **后端框架** | FastAPI | 高性能异步 REST API |
| **前端框架** | React 19 + Vite 7 | 现代 SPA 架构 |
| **原生封装** | Tauri v2 | Rust + WebView 跨平台 |
| **关系数据库** | PostgreSQL | 用户、消息、配置持久化 |
| **图数据库** | Neo4j | 代码语义索引、情节记忆 |
| **消息队列** | Redis + Celery | 异步任务处理 |
| **云集成** | EvoCloud (ThinkPHP) | 项目管理、远程控制 |
| **技能隔离** | Docker + MCP | 微服务化能力扩展 |
