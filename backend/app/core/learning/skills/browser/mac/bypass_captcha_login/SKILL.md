# 🧠 Expert Guide (心法)
This SOP dictates how to handle anti-bot friction (captchas) encountered during automated browsing. It prioritizes autonomous visual deduction before escalating to human intervention.

## Setup & Preconditions
1.  **Identify Captcha**: You must be currently viewing a page with a visible captcha challenge.
2.  **Ensure Visibility**: Make sure no browser toolbars or system dialogs obscure the captcha widget.

## Execution Matrix based on Captcha Type

### Type 1: Text/Image Recognition (Find the Traffic Lights)
1.  **Analyze Image**: Use `take_screenshot` to capture the entire captcha challenge box.
2.  **VLM Deduction**: Instruct the VLM (`analyze_image`) to identify the exact coordinates `(x, y)` of the requested objects (e.g., "all images with traffic lights").
3.  **Execute Clicks**: Use the `click` tool sequentially on each identified coordinate. Wait 0.5s between clicks.
4.  **Submit**: Click the "Verify" or "Submit" button within the captcha widget.

### Type 2: Slider/Puzzle (Drag to Fit)
1.  **Take Snapshot**: Use `take_screenshot` of the slider widget.
2.  **Identify Targets**:
    *   Find the **slider thumb** (usually a small button or arrow block). `(start_x, start_y)`
    *   Find the **target cutout/puzzle hole** in the main image. `(end_x, end_y)`
3.  **Calculate Offset**: Determine the horizontal distance `dx` between the thumb and the hole.
4.  **Execute Drag**: Use the `mouse_drag` tool to move from `(start_x, start_y)` to `(start_x + dx, start_y)`. Wait 1s after dragging before releasing (simulate human behavior).

### Type 3: Simple Checkbox (I am not a robot)
1.  **Locate Box**: Identify the empty checkbox next to "I'm not a robot".
2.  **Execute Click**: Click the center of the checkbox.
3.  **Verify UI State**: Wait 2-3 seconds for a green checkmark or an extended image challenge (Type 1) to appear.

## 🛟 Recovery Strategy
- **VLM Failure**: If the VLM repeatedly fails the captcha (e.g., solving "select bicycles" incorrectly twice), the site will flag you as a bot. You MUST immediately halt and use the `request_human_input` or `request_approval` tool, stating: "I am trapped in a Captcha loop. Please solve the captcha manually in the browser window, then type 'done' here."
- **Invisible ReCAPTCHA v3**: These rely on invisible tokens generated by JS based on mouse telemetry. If the login form submits but fails with an invisible captcha error, you currently cannot bypass it visually. Halt and request human assistance.
